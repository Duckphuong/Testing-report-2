\section{Giới thiệu}
Nhóm áp dụng các kỹ thuật kiểm thử hộp đen để thiết kế test case cho \textbf{Moodle LMS} (bản Docker theo
hướng dẫn của đề bài), gồm: phân tích giá trị biên (\textit{Boundary Value Analysis -- BVA}),
phân lớp tương đương (\textit{Equivalence Class Partitioning -- ECP}), bảng quyết định
(\textit{Decision Table}, phần cộng điểm) và kiểm thử theo use case (\textit{Use-case testing}).
Các test case được ghi trong file \texttt{.xlsx} theo mẫu của đề bài và được tự động hóa bằng \textit{Katalon Recorder}.

Mỗi thành viên chọn một feature riêng, không trùng nhau và không thuộc nhóm bị cấm (đăng nhập, đăng xuất, đổi mật khẩu
user mặc định). Mã test case có dạng \texttt{TC-XXX-YYY} với XXX là số thứ tự feature và YYY là số thứ tự test case.

\textbf{Tài liệu nộp kèm:} (1) báo cáo này (\texttt{.pdf}); (2) file \texttt{HEHE2027\_L01\_Proj2\_TestCases.xlsx};
(3) file nén \texttt{.zip} chứa các tệp \texttt{.krecorder}.

\subsection*{Quy định bổ sung của đề cần tuân thủ}
\begin{enumerate}[noitemsep]
  \item Mọi kỹ thuật phải được áp dụng cho \textbf{từng} feature. Nếu một kỹ thuật không áp dụng được về mặt logic
        (ví dụ bảng quyết định cho máy tính BMI, vì không có tổ hợp đầu vào nào cho kết quả khác nhau) thì không chọn feature đó.
  \item Mỗi sinh viên phải thể hiện hiểu biết về \textbf{tất cả} kỹ thuật bắt buộc, nên feature phải được chọn cẩn thận
        ngay từ đầu.
  \item \textbf{Phải chạy test suite Katalon Recorder} (ít nhất trên một trình duyệt, ví dụ Chrome) \textbf{trước khi tải về};
        log chạy được tải kèm test suite.
  \item File \texttt{.xlsx} dành cho \textbf{kiểm thử thủ công}: người kiểm thử làm theo cột \textit{Step name} và
        \textit{Step description} rồi đối chiếu với \textit{Expected Result}; đây không phải script Katalon.
        Cột \textit{Precondition} nêu rõ điều kiện trước khi test (ví dụ: đã đăng nhập bằng user nào, ngôn ngữ trình duyệt là English).
  \item \textbf{Không đổi mật khẩu của các user mặc định} trong Moodle demo.
\end{enumerate}

\section{Môi trường kiểm thử}

\section{Feature 001: Add a new user}

\subsection{Mô tả và hướng dẫn sử dụng}
Quản trị viên tạo tài khoản mới tại \textbf{Site administration $>$ Users $>$ Accounts $>$ Add a new user}
(URL: \texttt{<BASE\_URL>/user/editadvanced.php?id=-1}).

\textbf{Các bước sử dụng:}
\begin{enumerate}[noitemsep]
  \item Đăng nhập bằng tài khoản admin.
  \item Mở trang Add a new user.
  \item Nhập các trường bắt buộc (username, password hoặc chọn \textit{Generate password and notify user},
        first name, last name, email) và các trường tùy chọn (city, country, \dots).
  \item Bấm \textbf{Create user} (hoặc \textbf{Cancel} để hủy).
  \item Hệ thống kiểm tra dữ liệu; nếu hợp lệ thì tạo user và chuyển về \textit{Browse list of users}, nếu không thì
        hiển thị lỗi tại trường tương ứng và giữ nguyên form.
\end{enumerate}

nên min là 1 ký tự (rỗng bị báo ``Required'').
