\begin{itemize}[noitemsep]
  \item \textbf{Review script Katalon:} nhiều locator sinh động (\texttt{yui\_3\_18\_1\_1\_\dots}, \texttt{form\_autocomplete\_input-<số>},
        \texttt{course-info-container-7-4}, \texttt{moremenu-<hash>}) sẽ hỏng khi chạy lại hoặc chạy trên máy khác; đề xuất dùng
        \texttt{id=id\_\dots} và XPath theo \texttt{contains(@id, \dots)}.
  \item Lệnh verify của Katalon kiểm tra tên khóa học trong \textit{My courses} theo vị trí phần tử; đề xuất kiểm tra ngay trang khóa

  \item \texttt{F002-Cleanup.krecorder} xóa \emph{cả category} đầu tiên trong trang quản lý (\texttt{action-menu-toggle-1} $>$ Delete), có thể
        xóa nhầm dữ liệu không do test tạo; đề xuất chỉ xóa đúng các khóa học test đã tạo (theo id) trong \texttt{tearDown}.
  \item Short name cố định làm lần chạy thứ hai bị trùng; đề xuất thêm mã lần chạy \texttt{\{RUN\}} vào dữ liệu.
  \item Gộp 38 test case thành một kịch bản data-driven; tách Level 2 thành engine + file cấu hình; đề xuất 3 yêu cầu phi chức năng

  \item Đề gợi ý Python 2; AI đề xuất Python 3 vì Python 2 và Selenium cho Python 2 không còn được hỗ trợ (phù hợp hướng dẫn bổ sung của giảng viên).

        TC-002-010 và TC-002-012 không khớp hành vi thật (mục~\ref{sec:f002-findings}).
\end{itemize}
