\section{Giới thiệu}
Bài tập lớn 3 tự động hóa lại các test case của Bài tập lớn 2 bằng \textbf{kiểm thử hướng dữ liệu}
(\textit{data-driven testing}) viết bằng \textbf{Python 3}, \textbf{Selenium WebDriver} và \textbf{unittest},
đồng thời thực hiện \textbf{kiểm thử phi chức năng} (\textit{non-functional testing}) trên Moodle LMS.

\begin{itemize}[noitemsep]
  \item \textbf{Level 1:} các test case chỉ khác nhau về dữ liệu được gộp thành một script; dữ liệu đầu vào \emph{và}
        kết quả mong đợi (\textit{Expected Result}) nằm trong file \texttt{.csv}.
  \item \textbf{Level 2:} ngoài dữ liệu, \textbf{test item} (URL của site, locator của ô nhập, nút bấm\ldots) cũng được đưa ra
        file cấu hình/dữ liệu, script không còn chứa hằng số về giao diện.
  \item \textbf{Non-functional:} mỗi thành viên kiểm thử ít nhất một yêu cầu phi chức năng; báo cáo nêu loại kiểm thử, cách tiếp cận và công cụ.
\end{itemize}

\textbf{Thang điểm của đề:} Level 1 -- 5 điểm; Level 2 -- 2 điểm; Non-functional -- 2 điểm; báo cáo -- 1 điểm.

\subsection{Thiết kế script Level 1}
Mã đầy đủ nằm trong thư mục \texttt{F001/level1/} (hàm dùng chung ở \texttt{l1\_common.py}, ba script \texttt{test\_create\_user\_*.py}); đoạn dưới đây là bản rút gọn. Script dùng \texttt{unittest.TestCase}; mỗi dòng CSV chạy trong một \texttt{subTest}, nên một dòng sai không làm dừng các dòng còn lại và báo cáo ghi rõ test case nào fail.

\begin{lstlisting}[language=Python]
import csv, os, re, unittest
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

BASE = "http://127.0.0.1:9501"
DATA = os.path.join(os.path.dirname(__file__), "data_L1_create_user.csv")

def expand(v):                      # "<a*101>" -> "a" * 101
    return re.sub(r"<(.)\*(\d+)>", lambda m: m.group(1) * int(m.group(2)), v)

def read_rows(path):
    with open(path, newline="", encoding="utf-8") as f:
        return [{k: expand(v) for k, v in r.items()} for r in csv.DictReader(f)]

class CreateUserForm(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.d = webdriver.Chrome()
        cls.wait = WebDriverWait(cls.d, 10)
        cls.d.get(BASE + "/login/index.php")           # buoc chuan bi, khong phai doi tuong test
        cls.d.find_element(By.ID, "username").send_keys("admin")
        cls.d.find_element(By.ID, "password").send_keys("admin")
        cls.d.find_element(By.ID, "loginbtn").click()

    @classmethod
    def tearDownClass(cls):
        cls.d.quit()

    def set_checkbox(self, elem_id, want):
        box = self.d.find_element(By.ID, elem_id)
        if box.is_selected() != (want == "1"):
            box.click()

    def fill_form(self, r):
        d = self.d
        d.get(BASE + "/user/editadvanced.php?id=-1")
        for fid in ("username", "firstname", "lastname", "email", "city"):
            e = d.find_element(By.ID, "id_" + fid); e.clear(); e.send_keys(r[fid])
        self.set_checkbox("id_createpassword", r["generate_password"])
        if r["generate_password"] != "1":              # o password bi an, gan bang JS
            d.execute_script("arguments[0].value = arguments[1];",
                             d.find_element(By.ID, "id_newpassword"), r["password"])
        self.set_checkbox("id_preference_auth_forcepasswordchange", r["force_change"])
        self.set_checkbox("id_suspended", r["suspended"])
        d.find_element(By.ID, "id_submitbutton").click()

    def test_create_user(self):
        for r in read_rows(DATA):
            with self.subTest(tc=r["tc_id"]):
                self.fill_form(r)
                if r["expected_type"] == "success":
                    self.wait.until(lambda x: "/admin/user.php" in x.current_url
                                    or "Changes saved" in x.page_source)
                    self.assertIn(r["expected_text"], self.d.page_source)
                else:
                    err = self.wait.until(EC.visibility_of_element_located(
                        (By.ID, "id_error_" + r["error_field"])))
                    self.assertIn(r["expected_text"], err.text)

if __name__ == "__main__":
    unittest.main(verbosity=2)
\end{lstlisting}

\noindent\textbf{Lưu ý thiết kế:}
\begin{itemize}[noitemsep]
  \item \textbf{Dữ liệu độc nhất:} username/email trong CSV là duy nhất cho mỗi dòng và mỗi lần chạy phải xóa user đã tạo (hoặc đổi tiền tố); nếu không, lần chạy sau sẽ báo trùng.
  \item \textbf{Giới hạn \texttt{maxlength}:} ô First name/Last name/Email/City có \texttt{maxlength}, nên chuỗi 101 ký tự bị trình duyệt cắt còn 100; Expected Result của các dòng này phải khớp hành vi thực tế (ví dụ \texttt{success}).
  \item \textbf{Hộp thoại ``Reload site?''} do Moodle bật khi form đang sửa dở: script phải tắt cảnh báo này (hoặc dùng \texttt{get} sau khi đã submit) trước khi mở trang mới.
  \item Ô New password bị ẩn nên gán bằng JavaScript (không bị trình duyệt tự cắt); script tự cắt giá trị theo thuộc tính \texttt{maxlength} (128) để mô phỏng người dùng gõ, nên dòng 129 ký tự được kỳ vọng là \texttt{success} với mật khẩu 128 ký tự.
\end{itemize}

\subsection{Level 2: đưa test item ra ngoài script}
Ở Level 2, script không còn chứa URL hay locator. Ba file cấu hình bổ sung:

\begin{lstlisting}
config.csv        key,value
                  base_url,http://127.0.0.1:9501
                  login_path,/login/index.php
                  form_path,/user/editadvanced.php?id=-1
                  admin_user,admin
                  admin_pass,admin

locators.csv      name,by,value
                  username_input,id,id_username
                  submit_button,id,id_submitbutton
                  error_username,id,id_error_username
                  ...

form_fields.csv   data_column,locator,kind
                  username,username_input,text
                  password,password_input,password_js
                  suspended,suspended_checkbox,checkbox
\end{lstlisting}
Script Level 2 đọc \texttt{form\_fields.csv} theo thứ tự và với mỗi dòng gọi hành động tương ứng với \texttt{kind} (\texttt{text}, \texttt{password\_js}, \texttt{checkbox}); locator được tra trong \texttt{locators.csv} bằng \texttt{by} (\texttt{id}, \texttt{name}, \texttt{xpath}, \texttt{css}) ánh xạ sang \texttt{selenium.webdriver.common.by.By}. Cột \texttt{error\_field} của file dữ liệu cũng là một \textbf{tên locator} (ví dụ \texttt{error\_username}) chứ không còn là chuỗi id cố định.

\begin{lstlisting}[language=Python]
LOCATORS = {r["name"]: (BY[r["by"]], r["value"]) for r in read_csv("locators.csv")}
FIELDS   = read_csv("form_fields.csv")
CFG      = {r["key"]: r["value"] for r in read_csv("config.csv")}

def fill_form(self, row):
    self.d.get(CFG["base_url"] + CFG["form_path"])
    for f in FIELDS:
        by, val = LOCATORS[f["locator"]]
        el = self.d.find_element(by, val)
        if f["kind"] == "text":
            el.clear(); el.send_keys(row[f["data_column"]])
        elif f["kind"] == "password_js":
            self.d.execute_script("arguments[0].value = arguments[1];", el, row[f["data_column"]])
        elif f["kind"] == "checkbox":
            if el.is_selected() != (row[f["data_column"]] == "1"): el.click()
\end{lstlisting}
Khi giao diện đổi (ví dụ id của ô nhập thay đổi, hoặc nhóm chạy ở site khác) chỉ cần sửa \texttt{locators.csv} hoặc \texttt{config.csv}, không sửa script. Thêm trường mới vào form chỉ cần thêm một dòng vào \texttt{form\_fields.csv} và một cột vào file dữ liệu.

\begin{lstlisting}[language=Python]
BY_MAP = {
    "id": By.ID,
    "name": By.NAME,
    "css": By.CSS_SELECTOR,
    "xpath": By.XPATH,
    "class": By.CLASS_NAME,
    "tag": By.TAG_NAME,
    "link_text": By.LINK_TEXT
}

def locator(row, key):
    kind = row[f"{key}_by"].strip().lower()
    value = row[f"{key}_value"].strip()

    if kind not in BY_MAP or not value:
        raise ValueError(
            f"Invalid locator configuration: {key}"
        )

    return (BY_MAP[kind], value)
\end{lstlisting}

\subsection{Thiết kế script Level 1}
Mã đầy đủ nằm trong \texttt{F004/level1/test\_f004\_level1.py}; URL và locator (\texttt{id\_parent}, \texttt{id\_name}, \texttt{id\_idnumber}, \texttt{id\_submitbutton}, \texttt{id\_cancel}) là hằng số trong script. Đoạn dưới đây là bản rút gọn.
\begin{lstlisting}[language=Python]
def run_step(drv, row, step=1):
    repeat = int(row.get("repeat") or 1)
    for i in range(repeat):
        open_form(drv, step if i == 0 else 1)
        fill(drv, row["parent"], row["name"], row["idnumber"])
        if row["action"] == "submit":
            click_and_wait(drv, drv.find_element(By.ID, ID_SUBMIT))
        elif row["action"] == "cancel":
            click_and_wait(drv, drv.find_element(By.ID, ID_CANCEL))
    verify(drv, row, repeat)

def _make_test(tc_id, rows):              # one unittest method per tc_id
    def test(self):
        for step, row in enumerate(rows, start=1):
            run_step(self.drv, expanded(row), step)
    return test

for tc_id, rows in _load_cases().items():
    setattr(F004Level1, "test_" + tc_id.replace("-", "_"), _make_test(tc_id, rows))
\end{lstlisting}
\noindent\textbf{Lưu ý thiết kế:}
\begin{itemize}[noitemsep]
  \item \textbf{Ô Parent category} là danh sách tự động hoàn thành; script đặt giá trị cho thẻ \texttt{select} ẩn rồi phát sự kiện \texttt{change} (như lệnh \texttt{select} của Katalon ở BTL2), khớp tên đầy đủ hoặc phần cuối của đường dẫn ``cha / con''.
  \item \textbf{\texttt{maxlength}:} script dùng \texttt{send\_keys} nên tôn trọng thuộc tính này (TC-004-005 gõ 101 ký tự, kỳ vọng ô chỉ nhận 100); Katalon \texttt{type} ở BTL2 gán giá trị trực tiếp.
  \item \textbf{Đếm danh mục:} tên danh mục xuất hiện nhiều lần trên trang (cây danh mục, breadcrumb\ldots) nên script đếm riêng trong cây (\texttt{a.categoryname}); nếu không có cây thì chấp nhận từ một link trở lên.
  \item \textbf{Dữ liệu độc nhất:} tên và ID number chứa \texttt{\{RUN\}} nên chạy lại không bị trùng; giá trị 1 ký tự có xác suất nhỏ (khoảng 1/36) trùng với danh mục còn sót từ lần chạy trước, nên cần xóa các danh mục \texttt{tc004\_} và các danh mục tên 1--2 ký tự trước khi chạy lại. Script không tự xóa danh mục.
\end{itemize}

\subsection{Thiết kế script Level 1}
Mã nằm trong \texttt{F005/level1/}: \texttt{test\_choice.py} là điểm chạy,
\texttt{engine.py} chứa phần xử lý dùng chung, còn \texttt{settings.py} chứa URL và locator.
Script đọc CSV bằng \texttt{csv.DictReader}, giải mã các nhóm giá trị bằng \texttt{json.loads},
rồi chạy cùng hàm \texttt{scenario} cho từng dòng.

Đoạn dưới rút gọn cách kiểm tra ba nhóm luồng; các hàm thao tác trang được cài đặt trong
\texttt{ChoicePage}:

\begin{lstlisting}[language=Python]
def scenario(self, row):
    page, expected = self.page, row["expected"]
    page.edit_mode(True)
    before = page.activity_ids()
    page.go("create_url")
    page.fields(row["fields"])

    if expected["outcome"] == "cancelled":
        page.click("cancel")
        page.wait.until(lambda d: "/course/view.php" in d.current_url)
        self.assertEqual(before, page.activity_ids())
        return

    page.click("save")
    if expected["outcome"] == "error_then_created":
        error = page.element("error", field=expected["error_field"])
        self.assertEqual(expected["error_text"], error.text.strip())
        page.fields(row["repair"])
        page.click("save")

    cmid = page.wait_created()
    self.assertEqual(expected["title"],
                     page.element("activity_heading").text.strip())
    page.go("settings_url", cmid=cmid)
    for key, value in expected["saved_fields"].items():
        self.assertEqual(value, page.read_field(key))
\end{lstlisting}

\begin{itemize}[noitemsep]

        giá trị thực với \texttt{saved\_fields}; kiểm thêm số phương án đã lưu. Các ca 016, 017 và 024
        đều có phép kiểm tra kết quả, thay cho phần còn thiếu trong bản ghi Katalon.

\subsection{Chi tiết phần của Phát: tương thích của Add a Choice}
\textbf{Loại kiểm thử:} kiểm thử tương thích chức năng trên Chrome và Microsoft Edge.
Yêu cầu được lựa chọn là \texttt{NFR-COMP-001}: bốn luồng đại diện của Add a Choice phải chạy đạt
trên cả hai trình duyệt và cho dữ liệu đọc lại tương đương.

\textbf{Cách tiếp cận:} chọn TC-005-001 (tạo hợp lệ), TC-005-002 (thiếu tên rồi sửa),
TC-005-013 (cho phép chọn nhiều phương án) và TC-005-024 (Cancel).

CASES = ["TC-005-001", "TC-005-002", "TC-005-013", "TC-005-024"]

    ])
